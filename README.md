# 산불신호등 · 불티 작업 전 확인

옥외에서 용접·절단·그라인더·예초기처럼 불티가 나는 작업을 하기 전에,
현장에 붙은 QR을 찍으면 그 현장의 산불위험과 할 일을 보여 주는 웹입니다.

- 현장 화면: 지역 산불위험 등급(지금·앞으로 3일 작업시간대) + 현장에서 숲까지 거리 → 할 일 한 줄
  - 휴대폰 언어를 보고 한국어·English·中文·Tiếng Việt·ไทย·Bahasa Indonesia·Русский로 자동 표시(`i18n.js`)
- 감독자 화면(`register.html`): 주소 검색이나 지도 클릭으로 현장을 찍으면 전국 시군구를 자동으로 고르고,
  숲 자료가 있는 곳은 숲까지 거리를 계산해 인쇄용 QR(등급별 할 일 표 포함)을 만듭니다.

## 쓰는 자료
- 산림청 국립산림과학원_산불위험예보정보 (공공데이터포털 15084817, 시군구 단위, 3시간 간격 72시간 예보)
  — GitHub Actions가 15분마다 확인해, 자료가 2시간 30분 넘었으면 받아 `data/fire.json`으로 저장(예보가 그대로면 3시간까지는 저장 생략)
  — 예비: GitHub 예약 실행이 빠져 자료가 5시간 넘게 묵으면 관리자 PC가 대신 받아 올림
- 산림청 임상도 1:5,000 (2024, 산림공간정보서비스) — 숲(침엽수림·활엽수림·혼효림) 경계를 구별로 `data/forest/<구코드>.json`에 저장, 필요한 구만 내려받음
- 시군구 경계: vuski/admdongkor (행정동 경계 2025)를 산불위험예보 2026 지역코드(전남광주통합특별시, 인천 제물포·영종·서해·검단구)로 합쳐 `data/sigungu.json`
- 주소 검색: OpenStreetMap Nominatim(감독자가 [찾기]를 누를 때만 요청)
- 지도 자료 다시 만들기: `python scripts/build_geo.py <행정동경계.geojson> <임상도폴더> data/fire.json`

## 판단 기준
- 등급: 산림청 산불위험예보지수 구간(낮음 ~50, 다소높음 51~65, 높음 66~85, 매우높음 86~), 시군구 안 최댓값 기준
- 지금 값: 직전 예보와 다음 예보 중 높은 값(3시간 사이에 오르는 위험을 놓치지 않도록)
- 현장에서 100m 안에 숲이 있으면 등급대로, 멀면 '숲과 먼 곳'으로 안내
- 자료가 12시간 넘게 갱신되지 않으면 등급과 함께 '늦어짐' 안내, 24시간이 넘거나 지금 시각 예보가 없으면 '확인 불가'
- 숲 거리 자동 계산은 숲 자료를 받은 구(수원시 장안·권선·팔달·영통구, 서울 종로·성북구) 안쪽 100m까지. 그 밖은 감독자가 직접 고름
- 자동 수집은 받은 행 수가 전체 건수와 맞지 않으면 기존 자료를 그대로 둠
- 할 일 문구는 `common.js`의 `LEVELS`(한국어), `i18n.js`의 `T`(외국어)에서 고칩니다.
