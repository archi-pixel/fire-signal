# 산불신호등 · 불티 작업 전 확인

옥외에서 용접·절단·그라인더·예초기처럼 불티가 나는 작업을 하기 전에,
현장에 붙은 QR을 찍으면 그 현장의 산불위험과 할 일을 보여 주는 웹입니다.

- 현장 화면: 지역 산불위험 등급(지금·앞으로 3일 작업시간대) + 현장에서 숲까지 거리 → 할 일 한 줄
- 감독자 화면(`register.html`): 지도에서 현장을 찍으면 숲까지 거리를 계산하고 인쇄용 QR을 만듭니다.

## 쓰는 자료
- 산림청 국립산림과학원_산불위험예보정보 (공공데이터포털 15084817, 시군구 단위, 3시간 간격 72시간 예보)
  — GitHub Actions가 3시간마다 받아 `data/fire.json`으로 저장
- 산림청 임상도 1:5,000 (2024, 산림공간정보서비스) — 캠퍼스 주변 숲 경계를 `data/forest.geojson`으로 변환

## 판단 기준
- 등급: 산림청 산불위험예보지수 구간(낮음 ~50, 다소높음 51~65, 높음 66~85, 매우높음 86~), 시군구 안 최댓값 기준
- 현장에서 100m 안에 숲이 있으면 등급대로, 멀면 '숲과 먼 곳'으로 안내
- 할 일 문구는 `common.js`의 `LEVELS`에서 고칩니다.
